Pre-ship (build-side) security and runtime security solve different problems. Pre-ship security testing establishes what your firmware is built from and what's actually reachable before release; runtime security watches device behavior after deployment. They work best in sequence, and pre-ship comes first, because a monitor can only ever act on the software you already shipped.
